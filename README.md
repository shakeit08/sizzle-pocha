# 원본 에셋 보관

ChatGPT로 뽑은 원본 그대로입니다(크기 변경·재압축 없음).

- 0_그림체레퍼런스: 그림 뽑을 때 첨부하는 기준 그림
- 1_캐릭터시트: 표정 4개짜리 시트 원본 (팔수정본: 잘린 팔을 채운 포즈)
- 2_CG: 게임에 쓰는 CG 원본
- 3_메인화면: 시작 화면 그림
- 4_배경: 대화 장면 배경
- 5_게임판: 꼬치 퍼즐 그림 조각(꼬치·철판·접시·아이템·손님·특별 손님 NPC 등, 웹앱·플러그인 공통)
- 6_방: 홈 화면 방 바탕과 수리 파츠 원본 + 배치값(layout.json)
- 4_배경/예전그림체_교체예정: 아직 게임에 쓰이는 예전 그림체 배경 4장(새로 뽑으면 교체)
- 7_안내: 게임 안 플레이 방법 이미지
- 원본시트: 자르기 전 통짜 원본 시트 (안쪽 폴더는 위 번호와 같게 나눔, 이름은 `분류_내용_번호.png`)
